### 1.4 Texto y avisos del paper que importan para el bloque

- Referencias: [12] Hoek, E. 1990, «Estimating Mohr-Coulomb friction and cohesion values from the Hoek-Brown failure criterion», IJRMMS 12(3), 227–229; [13] Hoek, E. 1994, «Strength of rock and rock masses», ISRM News Journal 2(2), 4–16; [20] Balmer, G. 1952, *ASTM* 52, 1260–1271. ### 3.2 OGR: texto clave

- «The methods need the strength on the plane of the slice base… For a given σ′n it finds the failure circle that touches the envelope there.» Newton con cota y bisección sobre x = mb σ′3/σci + s; tanφ_i = (k−1)/(2√k), lo que equivale a sen φ = (k−1)/(k+1). [verificado]
- «With the default constants the envelope gives 307.5 kPa at σ′n = 0 for the generalised model … It ends at (−σt, 0)». [verificado]
- Ordinary (un paso, sin iteración): «An effective normal force that comes out negative is set to zero before the envelope is read, so that base contributes its cohesion only.» [verificado, methods.html]

### 3.3 SLOPE/W: texto clave

- «SLOPE/W computes σ1 for a range of σ3 values. The default range for σ3 is from the tensile strength … up to half of the uniaxial compressive strength.» y «SLOPE/W calculates the parameters for the equation of a line that is tangent to the strength function at any given base normal stress.» [verificado, manual §7.14 p. 129]

| Programa | Convención | Medición o cita |

Medición del motor (círculo fijo con N′ < 0, UCS 5 MPa, GSI 30, mi 8, D 0; FS = 1,8028; aviso `negative-effective-normal`):
- dovela 0: σ′n = −0,878 kPa → c = 11,0731 kPa y φ = 61,1233° (salida del oracle), igual que la tangente de σ3 = 0 (11,0731 y 61,1233). La resistencia de esa base es c + σ′n·tanφ = 11,07 − 0,88·1,80 ≈ **9,5 kPa a tracción**. [verificado]
- dovela 31: σ′n = 4,436 kPa < sn(0) = 5,347 kPa → c = 11,0874 y φ = 61,0918 (la tangente de σ3 = 0 con el residuo de promedio). [verificado]
- Por tanto cSlope **sí** asigna resistencia positiva a σ′n < 0 y **no** la rechaza (solo avisa). La tangente de σ3 = 0 con φ ≈ 61° no tiene base física en tracción. [inferido: lectura del código y de la salida]

## 7. Riesgos, recomendación y preguntas abiertas

### 7.1 Decisiones que quedan para X28 (tabla)

| Decisión | Opciones | Evidencia de este documento | Propuesta |
|---|---|---|---|
| Tangente en σ′n | (a) instantánea en σ′n de cada dovela (cSlope, OGR, SLOPE/W); (b) ajuste lineal de Hoek 2002 (eqs. 12–13) en un σ3max | (a) es lo que hacen los tres programas leídos; (b) no lo usa ninguno de los tres; con (b) la sobreestimación no se mide aquí | (a), con la nota de Hoek (1994) en la Ayuda |

| σ′n ≤ 0 | (a) tangente de σ3 = 0 (cSlope); (b) envolvente en σn = 0 con raíz σ3 < 0 (OGR); (c) corte: τ = 0 si σ′n ≤ 0 | (a): φ 61,4°, c 5,07 kPa, dio 9,5 kPa a tracción; (b): φ 66,8°, c 4,59 kPa | Decidir en X28 con el oráculo; (c) es la opción más defensiva, pero el oráculo no la tiene, así que la comparación no sería directa |

### 7.2 Riesgos

- **Tangente sobreestima entre σ′n:** la misma línea MC (una sola tangente) da +2,8 a +3,3 % de FS en el rango medio y +66 % cerca de 0 (§4.2). La tangente por dovela evita el error porque se evalúa en cada σ′n. [verificado para el círculo; patrón general [inferido]]
- **Residuo del promedio:** 0,16 kPa de desfase (§4.3); aceptable para la tolerancia 1e-4 de F, pero el oráculo no permite variar las pasadas. [verificado]
- **Unidades:** un error de 1000× en σci da FS = 0,28 sin aviso (§5.2). Es el riesgo más alto para el usuario. [verificado]
- **σ′n ≤ 0:** cSlope da resistencia a tracción en las dovelas de la cresta (§3.4). [verificado]
