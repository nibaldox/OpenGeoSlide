# Briefs

Esta carpeta conserva, por trazabilidad, los documentos con los que se coordinó el desarrollo de OpenGeoSlide.

- **`00_CONTRATOS.md` y `01_CONTRATOS_FASE1.md` son el contrato normativo:** definen el formato `.ogs.json`, las
  convenciones numéricas, las tolerancias y los criterios de aceptación. Son los únicos documentos de esta carpeta que
  describen el comportamiento esperado del software.
- **El resto de los archivos son instrucciones de trabajo** para los agentes de desarrollo que construyeron cada parte
  (motor, web, verificación, publicación). Son registros históricos: mencionan las rutas del entorno original
  (por ejemplo, worktrees y directorios de la máquina del autor), que no existen en otros equipos, y no se mantienen.

Para usar el software no hace falta leer esta carpeta: véanse el [README](../README.md), el
[CHANGELOG](../CHANGELOG.md) y `docs/`.
